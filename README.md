Terraform IaC configuration that provisions and manages one or more **Google Cloud Storage (GCS) buckets** on GCP.

---

## Overview

This repository is a Terraform root module that creates `google_storage_bucket` resources on GCP. The entire public interface is a single `gcs_config` variable — a map of bucket configuration objects — which drives naming, location, storage class, versioning, access settings, and labels for each bucket. The root module invokes the remote reusable module [`subhamay-bhattacharyya-tf/terraform-google-gcs-bucket`](https://github.com/subhamay-bhattacharyya-tf/terraform-google-gcs-bucket) (ref: `main`), with labels automatically enriched in `locals.tf` before being passed through. Three environments are supported — `devl`, `test`, and `prod` — each with a dedicated `tf/environments/<env>/auto.terraform.tfvars.json` file selected via `-var-file` at plan/apply time. Remote state is managed via Terraform Cloud.

## Notes & Caveats

> **Destructive operation:** Setting `force_destroy = true` allows Terraform to delete a bucket even if it contains objects. Use with caution in `prod` — the default is `false`.

- `versioning_enabled` defaults to `false` in `devl`/`test` and `true` in `prod` for data durability.
- Bucket names are globally unique in GCP — choose names that will not conflict with other projects.
- `uniform_bucket_level_access` cannot be disabled once enabled on a bucket.
- Labels are automatically enriched with `environment` and `managed_by = "terraform"` in `locals.tf`.

## CI / Workload Identity Federation Setup

The CI workflow authenticates to GCP via [Workload Identity Federation](https://cloud.google.com/iam/docs/workload-identity-federation). If the job fails with `Permission 'iam.serviceAccounts.getAccessToken' denied`, grant the WIF pool principal the required IAM binding:

```bash
gcloud iam service-accounts add-iam-policy-binding \
    "<service-account-email>" \
    --project="<gcp-project-id>" \
    --role="roles/iam.workloadIdentityUser" \
    --member="principalSet://iam.googleapis.com/projects/<project-number>/locations/global/workloadIdentityPools/<pool-name>/attribute.repository/subhamay-bhattacharyya/terraform-gcs-bucket-demo"
```

The repository variables required by the CI workflow are:

| Variable | Description |
| -------- | ----------- |
| `GCP_PROJECT_ID` | GCP project ID passed as `GOOGLE_CLOUD_PROJECT` to Terratest |
| `GCP_WORKLOAD_IDENTITY_PROVIDER` | Full WIF provider resource name |
| `GCP_SERVICE_ACCOUNT` | Service account email to impersonate |
